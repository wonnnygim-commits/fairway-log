# 페어웨이 · 나의 골프 기록

아이폰용 모바일 우선 골프 라운드 기록 웹앱 초안. 별도 서버·계정 없이 브라우저에 저장합니다.

## 실행

이 디렉터리에서 `python3 -m http.server 8080` 실행 후 `http://localhost:8080`을 엽니다.
배포된 HTTPS 주소를 iPhone Safari에서 열고 공유 → 홈 화면에 추가하면 앱처럼 사용할 수 있습니다.
최초 온라인 로딩 이후 서비스 워커 캐시로 오프라인 실행을 지원합니다.

## 기능

- 오늘 날짜 기본값, 골프장 자동완성/직접 입력, 코스명과 동반자
- 전후반 18홀 파·그린까지 타수·퍼팅·GIR·메모, 자동 저장
- 중단 저장, 이어쓰기, 완료 기록 수정 및 삭제
- 날짜 범위/골프장 필터, 총타수·홀당 퍼팅·GIR·홀당 파 대비 차트
- JSON 백업 내보내기/가져오기 (중복 ID는 기존 기록 유지)

## 계산 기준

총타수 = 그린까지 타수(벌타 포함) + 퍼팅 횟수. GIR 자동값은 그린까지 타수 ≤ 파 − 2입니다.
그린 이탈 등 자동 계산이 부정확한 경우 GIR을 직접 지정할 수 있습니다.
통계는 입력 확인을 마친 홀만 포함합니다. 총타수 차트와 홈 평균은 18홀 완주만 포함하고,
나머지 차트는 선택 시 중단 기록도 포함합니다. 날짜 간 실제 간격을 반영하며 같은 날짜 점은 겹칠 수 있습니다.

## 데이터와 한계

골프장 이름·지역: 한국골프장경영협회 회원사 목록 https://www.kgba.co.kr/03sub01 (2026-10-26 확인, 209개).
전국 전체 골프장 데이터가 아니며 홀별 파는 제공하지 않습니다. 미등록 골프장은 직접 입력합니다.
개인 라운드 데이터는 해당 기기·브라우저·주소의 localStorage에만 저장되며 외부 전송하지 않습니다.
기기 간 동기화는 없습니다. Safari와 홈 화면 앱 간 저장소 공유를 보장하지 않으니 사용할 화면을 정한 뒤 기록하세요.
브라우저 데이터 삭제·OS 저장소 정리·기기 교체에 대비해 백업을 권장합니다.
앱의 코드·골프장 목록은 공개되어도 개인 기록은 공개되지 않습니다.

## 검증

Chrome 모바일 390×844 시뮬레이션: 자동완성, 재로딩 후 초안 복원, 중단/이어쓰기,
18홀 합계 73타, 완주/중단 차트 구분, 날짜·코스 필터, 가로 넘침 없음, JSON 내보내기/복원 통과.
실물 iPhone Safari 검증은 아직 하지 않았습니다.
